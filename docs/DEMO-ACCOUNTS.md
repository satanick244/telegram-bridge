# 线上只读演示账号

在账号登录页选择「买家演示 · 只读」或「供应商演示 · 只读」，无需密码即可进入两个独立的功能展示账号。

- 买家演示账号标识：`induport_demo_buyer_v1`，默认打开风险档案。
- 供应商演示账号标识：`induport_demo_supplier_v1`，默认打开业务总览。
- 不提供管理员演示。两个账号都是公开共享的只读账号，不能输入或保存个人信息，不能上传文件、导入、发布商品、下单、审批、授信或核销。正式业务使用自己的注册账号。
- 账号由首次进入演示时在事务内创建；内部使用随机密码的 scrypt 哈希，没有公开、固定或默认密码，也不会修改实际管理员的登录配置。
- 每位访客取得独立的 HttpOnly/SameSite 会话，线上 Cookie 启用 Secure；演示会话有效期一小时。退出只撤销当前访客的会话。演示登录与普通登录共同受来源校验和频率限制保护。
- 已登录真实账号时，不会被演示入口静默替换；请先退出自己的账号，再进入演示。保留名称如与已有真实账号冲突，接口报错并保留原账号，不覆盖现有数据。

## 示例内容与真实性边界

每个演示账号各有九份完整情景档案、九份风险合同、测算快照、额度/回款算例和人工处置建议，并按测算结果提供预警工单。情景名称以「【情景预估】」开头，标记 `source=estimate`；虚构业务界面样例标记 `source=example`，全部带有 `isDemo=true`。

真实注册、财务和履约依据保留为 null，单独注明未核验；完整的经营情景使用明确标注的假设指标展示，不会捏造统一信用代码、认证文件、企业信用评级或真实联系人。示例邮箱使用保留的 `.invalid` 域名。示例图片仍使用原有已记录来源的品类摄影，不表示该虚构企业的产品实拍。

演示规则使用独立的初始假设（1/7 天、5%/3%/10%），不读取真实管理员的规则调整理由或私有档案。没有“低风险”结论。额度/收款算例使用单独的 `demo_case` 类型，不创建真实 credit、ledger 或审批记录。

工作台还展示一个明确标注的虚构商品、供应商、订单和询价，用于查看报价、库存、状态、单证等界面。它们封装在该演示账号的 `demo_business` 记录中，**不写入实际商品、供应商、订单或询价表**，也不会作为真实供应信息出现在未登录或真实账号视图中。导出的单证标注为 DEMO / FICTIONAL，示例产品及买方名称保留演示前缀。

页面始终显示「演示账号 · 只读」提示。演示资料不能证明网站已经拥有真实客户、供应商、库存或交易；它们只用于说明功能。公开采购目录维持原有 48 款选型条目。

## 隔离、维护及备份

普通用户和真实管理员的常规风控列表、统计、预警扫描均排除演示记录；演示用户不能通过接口访问真实档案、审计内容、管理员列表或数据库迁移备份。真实管理员也不能通过正常业务接口把演示档案改为真实资料。

演示数据在现有 MySQL/SQLite 存储内以来源标记和账号边界隔离，不需要新建数据库服务、付费资源或密钥。示例日期以首次初始化的时间为基准，不代表实时账龄或真实催收。共享账号只读，因此不需要访客结束后重置内容。

初始化使用持久化风控锁防止并发重复创建，并记录带 `isDemo` 标记的 `demo.seed` 审计事件。常规业务审计列表隐藏这些演示事件，但完整哈希链校验和管理员迁移备份会包含它们，以保证链完整；备份中的随机密码哈希同样需要私下保管。首次创建后重复登录不会重复生成资料或审计事件。

## 验证

`npm test` 包含两个角色、只读接口、账号隔离、真实统计、保留名称冲突、CSRF、过期、频率限制及规则保密检查。`npm run test:e2e` 包含登录入口、示例档案、额度算例、手机布局、单证标记、退出和正常注册流程。

配置 `MYSQL_TEST_CONFIG_FILE` 后，MySQL 测试额外验证跨连接并发首次登录只生成一套演示数据，以及重开存储后资料保留。只允许隔离的 localhost `_test` 数据库；线上核验只通过专门的演示入口创建已授权的演示资料，不写入真实交易数据。

## 第二版：完整情景案例库

风控演示现在默认打开「情景案例库」，两个角色各有 **9 组**预估档案、风险合同、测算快照、收款/额度算例与处置建议，覆盖：

| 情景 | 主要观察点 |
| --- | --- |
| 肯尼亚热轧卷 | 正常账期、压力后仍有毛差 |
| 尼日利亚螺纹钢 | 基准毛差 30,000 CNY，压力后 -26,060 CNY |
| 乌干达镀锌卷 | 其他占用加本单应收后，假设授信缺口 39,120 USD |
| 加纳型钢 | 假设已收 50%，余额逾期 3 天 |
| 坦桑尼亚钢卷 | 假设已收 10%，余额逾期 12 天，升级复核 |
| 塞内加尔钢管 | CFR 本方海运费为 USD，净汇率敞口与运费上升压缩毛差 |
| 国内钢材采购 | 千克/吨换算，21,600 CNY 供应商预付款敞口单列 |
| 越南不锈钢 | 新客假设历史订单为 0、未授信，不能推断良好履约 |
| 阿联酋钢卷 | 假设已全额收款，原到期日已过也不再计逾期 |

数量、币种、条款、材料单位成本、物流承担、汇率、额度、其他合同占用、收款、到期日均为明确输入；另外提供经营年限、年营业收入、流动比率、历史订单/逾期数量、按时履约比例、结算和保障安排的假设。履约比例按假设历史订单与逾期数量计算；无历史时显示不适用，不把未知当作零风险。

这些值按经营逻辑构造，**不是当前市场报价、真实客户经营数据或经过历史校准的统计预测**。时间以情景初始化时的基准日固定，规则快照、输入来源与版本跟随情景保存，避免日期推移后所有案例都变成逾期。毛差仍只覆盖材料和运费口径，不代表完整净利润。

「情景输入完整」表示推演所需的数值已明确，**不等于真实企业资料已核验**。实际注册资料、财务原件和履约凭据仍为 null；页面用独立的“情景设定”和“真实资料未核验”说明它们，绝不伪造证照编号或确认认证。真实账号的缺失资料校验规则保持原有行为。

演示额度、回款及处置建议分别存为独立 demo_case/demo_review，不创建真实 credit/ledger/approval。既有 v1 演示账号会在登录或刷新读取时以事务升级到 v2，保留旧数据、原密码哈希和原审计记录，只展示当前版本案例；升级只追加一次 demo.upgrade 审计事件。升级中途失败则全部回滚，重试不会重复建档。旧快照作为历史保留。线上 `/api/health` 的 `demoVersion` 为 `forecast-demo-v2`。
