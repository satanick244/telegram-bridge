# SteelFlow · 钢贸出口协作平台

一个可运行的全栈业务原型，面向钢铁出口的供应商、买家和平台运营人员。界面为中文，商品按美元 / 公吨计价。内置 3 家示例供应商、6 款钢材与 4 笔订单。

**当前属于共享演示空间，尚不能作为真实 SaaS 对外运营。** 已实现数据持久化与交易流程，但没有登录认证、企业数据隔离、真实收付款或外部物流连接。公开演示只使用示例资料，请勿录入真实敏感业务信息。

## 本地运行

需要 **Node.js 24 或更高版本**（使用内置 `node:sqlite`）。

```bash
cd /workspace/telegram-bridge
npm ci --cache /workspace/.npm-cache
npm run dev
```

开发服务监听 `0.0.0.0:3000`，前端与 API 共用端口。可通过环境变量 `PORT` 更换端口。

生产模式验证：

```bash
npm run build
npm start
```

SQLite 文件默认位于 `data/steelflow.db`，可通过 `DATABASE_PATH` 指定。数据库目录与生成文件已加入 `.gitignore`。示例数据仅在空数据库初始化时写入；重启服务不会清除用户录入内容。备份请在停服后复制整个 `data/` 目录。

## 已实现的流程

| 模块 | 行为 |
| --- | --- |
| 业务总览 | 数据库订单统计、采购待办、优选商品、最近订单；历史趋势明确标记为示例 |
| 全球采购市场 | 品类、港口、供应商筛选，搜索、排序、浏览详情与本地收藏 |
| 供应商入驻 | 企业资料校验、统一信用代码格式及重复检查、申请持久化、演示审核 |
| 商品管理 | 新建出口商品、牌号规格、库存、起订量、FOB/CIF/CFR/EXW、上架与下架 |
| 询价与报价 | 买家提交需求、供应商回复单价、询价状态管理 |
| 买家采购 | 按服务端售价创建订单，验证整数采购量、起订量和库存，原子预留库存 |
| 订单管理 | 筛选搜索、订单详情、履约状态推进与历史、CSV 导出 |
| 利润工作台 | CNY 成本换算、USD 收入、运费、平台费、固定费用、利润率与单吨收益、CSV 导出 |
| 订单收益 | 每笔订单商品收入、采购成本、平台费、预估毛利；新订单保存测算成本及汇率快照 |
| 物流跟踪 | 基于订单状态展示示意路线和履约节点；不是实时追踪 |
| 贸易单证 | 形式发票草稿预览、订单数据导出；不是法定单证 |
| 企业设置 | 当前浏览器中的演示资料保存 |

右上角头像可以切换三个演示视角。切换只改变导航入口，**不构成权限控制**。全局搜索支持 Ctrl / Cmd + K，弹窗支持 Esc 和键盘焦点循环。手机端使用抽屉导航，表格独立横向滚动。

## 收益口径

- 测算收入 = USD 单价 × 数量。
- 采购成本 = CNY 单吨采购价 ÷ CNY/USD 汇率 × 数量。
- 平台费 = 测算收入 × 费率。
- 预计利润 = 收入 − 采购成本 − 逐吨物流费用 − 固定费用 − 平台费。
- 订单收益表暂不计物流与其他费用，使用 7.12 汇率、2% 平台费的演示假设。页面明确标注估算口径，不能作为实际结算或可提现余额。
- 汇率是手工输入，不是实时行情。没有自动计入出口退税、进口税、保险、融资与汇兑损益。

## 验证

```bash
npm test
npm run test:e2e
```

接口测试使用内存数据库，覆盖成本计算、入驻审核、商品验证、报价、订单价格防篡改、库存不足和并发下单。浏览器测试自动启动独立的 3001 端口服务和内存数据库，不污染开发数据库。

浏览器测试默认复用 `/usr/bin/chromium`；也可设置 `CHROMIUM_PATH`。其他环境先运行 `npx playwright install chromium`。字体、图标和摄影素材在本地提供，页面不依赖第三方图片或字体请求。

## 代码结构

- `src/main.jsx`：工作台、采购、供应、订单、收益等页面与交互。
- `src/styles.css`：视觉系统、响应式布局与可访问性样式。
- `server/app.js`：输入校验及交易 API。
- `server/db.js`：SQLite 数据存储与示例数据。
- `server/domain.js`：费用、利润及订单业务规则。
- `tests/`：接口与 Playwright 端到端测试。
- `docs/PRODUCT.md`：产品边界、交易设计和商用迭代建议。
